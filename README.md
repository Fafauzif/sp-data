# LihatDulu project handoff

This repository carries the proposal work, reviewer history, evidence, and editable visual sources from the 25 November 2026 UISP16 revision. It is designed to be cloned into a fresh session. The marketplace application and the reference repositories are linked separately.

## Start here

1. Read [the current context](docs/CURRENT-CONTEXT.md) and [the original chat feedback](docs/CHAT-FEEDBACK.md).
2. Open the [revised Word proposal](revision/output/LihatDulu_UISP16_Proposal_Revised.docx). The [31-page PDF preview](revision/finalqa/LihatDulu_UISP16_Proposal_Revised.pdf) shows the layout checked in this session.
3. Read [all prior Word comments](docs/WORD-REVIEW-COMMENTS.md). The [commented proposal (3)](upload/LihatDulu_UISP16_Proposal%20%283%29.docx) preserves the 27 original comments in Word, including replies and their anchors. Proposal (2) is also included.
4. Use the [historical master context pack](upload/LihatDulu_MASTER_AI_CONTEXT_2026-11-25_Updated.md) for the technical and competition history. Where the master predates the latest decisions, use the current context for this revision.
5. Use [sources and clone commands](docs/SOURCES-AND-REPOS.md) to recover related repos, check provenance, or rebuild. A finished DOCX and its placed figures are already included.

Extract the ZIP and upload the **contents of this folder** to GitHub, or initialize and push it with Git. Use a private repository for the draft, original comments, respondent-level survey answers, and third-party reference files. The template deck and watermarked examples are for reference.
